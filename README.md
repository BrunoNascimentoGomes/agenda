# Agenda (celular)

Versão para celular (PWA) da Agenda: calendário do Google Agenda e tarefas do Google Tasks.

**Abrir:** https://brunonascimentogomes.github.io/agenda/

**Instalar no celular**
- **Android (Chrome):** abra o link › menu ⋮ › **Instalar app**.
- **iPhone (Safari):** abra o link › **Compartilhar** › **Adicionar à Tela de Início**.

Os dados ficam na sua conta Google; este repositório só tem o código do app.
Demonstração sem conta: https://brunonascimentogomes.github.io/agenda/?demo

Ao publicar mudanças, aumente `VERSAO` em `sw.js` para os celulares baixarem a versão nova.
